# Student Management CRUD Web Application

## 📌 Project Overview

Student Management CRUD is a simple web application developed to manage student records.

The application allows users to perform the four basic CRUD operations:

- Create – Add a new student
- Read – View student records
- Update – Edit existing student details
- Delete – Remove student records

The project is developed using HTML, CSS, and JavaScript.

---

## 🎯 Objectives

- To develop a simple CRUD-based web application.
- To create a user-friendly student management interface.
- To implement Create, Read, Update, and Delete operations.
- To perform client-side form validation.
- To provide a search facility for student records.
- To understand basic frontend web development concepts.

## ✨ Features

### 1. Add Student
Users can enter student details such as:

- Student Name
- Email
- Department
- Year

After submitting valid information, the student record is added to the list.

### 2. View Students
All saved student records are displayed in a table.

### 3. Update Student
Users can select the **Edit** button to modify existing student information.

### 4. Delete Student
Users can delete a student record using the **Delete** button.

### 5. Search Student
Users can search for students using the search box.

### 6. Form Validation
The application checks:

- Empty fields
- Valid email format
- Department selection
- Year selection
